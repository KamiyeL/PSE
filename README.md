# PSE-FS2026: Odoo IoT für Digital Signage

## Kurzbeschreibung
Ziel unseres Projekts ist die Entwicklung eines Odoo-Moduls, das es ermöglicht, Informationen aus Odoo auf TRMNL E-Ink-Displays darzustellen sowie diese Displays direkt aus Odoo heraus zu verwalten.  
Dieses Repository enthält die von der Universität Bern geforderten Dokumente und setzt unseren Arbeitsplan über Issues und ein Git-Project um.

Der Projektcode ist im Repository unseres Kunden Abilium verfügbar:  
[https://github.com/Abilium-GmbH/pse_trmnl_odoo_connector](https://github.com/Abilium-GmbH/pse_trmnl_odoo_connector)

Für mehr Informationen zum Arbeitsplan siehe:  
[work_plan_description.md](docs/work_plan_description.md)
