## 1. Besprechung Vorgehen Iteration 3
Nach dem Meeting mit Abilium haben wir abgesprochen, dass wir uns als nächstes darauf konzentrieren, wie wir eine generische Implementation für die Darstelung von bestehenden Odoo Apps entwicklen wollen. Zudem auch noch abklären, ob es möglich ist, unser eigenes Odoo Modul als API Server bei TRMNL zu nutzen. 

## 2. Update TRMNL API Server
Nach erstem Einlesen scheint es möglich zu sein, dass man Odoo als API Server in TRMNL nutzt. Allerdings sind wir uns noch sehr unsicher, wie man eine adäqute Verschlüsselung beim Übertragen der Daten sicherstellen kann. Dies ist jedoch ein zentraler Punkt, da auf dem TRMNL auch sensible Daten dargestellt werden sollen. Wir werden uns hier weiter einlesen und gegenbenfalls Zühlke kontaktieren für Unterstüzung.
