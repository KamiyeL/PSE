**Datum:** 01.04.2026

## 1. Update Projektstand
Wir konnten unser TRMNL Modul in Odoo erweitern. Es ist nun möglich zwischen einer Wochen- und Monatsansicht für den Kalender zu wählen. Damit haben wir das Ziel der 2. Iteration entsprechend umsetzen können. 

## 2. Ziele nächste Iteration
### 2.1 Generische Implementierung
Der Kunde wünscht sich, dass wir unser Odoo Modul so erweitern/umschreiben, dass die Implementation für die Darstellung auf dem TRMNL Display generisch sind. In Odoo gibt es eine Ansicht der Inhalte mit HTML-Files. In Absprache mit dem Kunden werden wir versuchen die relevanten Teile der HTML-Datei aus Odoo für die Ansicht extrahieren, so dass dies generisch für alle Module die Darstellung auf dem Display ermöglicht. 

### 2.2 Eigener Server für TRMNL Display
Der Kunde wünscht, dass wir abklären ob es möglich ist als API Server einen Link auf unser Odoo Modul zu verwenden. Danach müsste man die Logik und Kryptografie, welche vom TRMNL Server genutzt wird, in Odoo implementieren können, so dass wir den Server von TRMNL nicht mehr benötigen. 

## 3. Nächster Termin
Für die Besprechung der 3. Iteration und das Planen der 4. Iteration haben wir einen Termin am 21.04.2026 vereinbart.
